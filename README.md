# Mars Frontier

Колонизаторный idle-игр с системой эпох, престижей и облаковыми сохранениями.

## Тестирование

**Ссылка для тестирования (любое устройство):**
https://shiyota.github.io/mars-frontier/

Работает на любых устройствах с браузером — ПК, планшеты, смартфоны.

## Описание

Развивай колонию на Марсе, переходя от звезды к звезде. Начни с Проксимы Центавра и дойди до Сверхзвёздного скопления.

**Особенности:**
- 5 эпох с уникальными звёздами
- 15 типов зданий
- 29 заданий
- Система престижей с токенами
- Сохранение в облаке (Яндекс ID)
- Адаптивный интерфейс (ПК + мобильные)
- Русский и английский языки

## Технологии

- Чистый HTML/CSS/JS (без фреймворков)
- Яндекс Games SDK (звук, реклама, сохранения, авторизация)
- Web Audio API для звуковых эффектов
